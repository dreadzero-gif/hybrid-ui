# 🌌 Hybrid UI
A modern MMO‑grade interface framework inspired by Final Fantasy XIV, Elder Scrolls Online, and Guild Wars 2.

Hybrid UI merges cinematic clarity with modular design, offering frames, bars, gauges, themes, presets, animations, and combat tools for both standalone UI development and Blish HUD integration.

---

## ✨ Features
- FF14‑style frames  
- ESO‑style buff bars  
- Profession gauges  
- Cast bar  
- Theme engine  
- Preset engine  
- Animation engine  
- Combat adapter  
- Blish HUD module  
- Standalone UI framework
