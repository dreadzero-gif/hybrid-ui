# Hybrid UI Framework

Hybrid UI is a modular, theme‑driven HUD framework designed for Guild Wars 2 addons and Blish HUD modules.

It provides:
- Player and target frames
- Buff bars
- Gauges
- Combat overlays
- Themes
- Presets
- Animations

Hybrid UI is built for creators who want to design custom HUDs without rewriting the entire UI stack.

## Features
- Theme engine (Gold, Obsidian, Azure, Crimson)
- Preset system for full HUD layouts
- Combat adapters (breakbars, boss timers, mechanic alerts)
- Animation engine (pulse, glow, rotate, fade)
- Modular components (frames, bars, gauges)
- Asset‑driven design (icons, textures, themes)
